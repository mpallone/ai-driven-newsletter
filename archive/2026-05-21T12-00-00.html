Gemini CLI is being retired; Antigravity CLI is the replacement

  • Source: Google Developers Blog
  • Link: Transitioning Gemini CLI to Antigravity CLI — Google Developers Blog
  • TL;DR: Google announced at I/O 2026 (May 19–20) that Gemini CLI is being shut down for free, Pro, and Ultra users on June 18, 2026. The replacement is Antigravity CLI — a Go rewrite of the Node.js-based Gemini CLI that shares the same agent harness as the new Antigravity 2.0 desktop app. Your existing Agent Skills, Hooks, and Subagents carry over; Extensions are renamed Antigravity plugins. Skills work the same way as before: they sit dormant and load into context on demand when a request matches the skill's description. API-key users and enterprise Gemini Code Assist licenses get more time before the cutoff.
  • What to do: Install Antigravity CLI and test your existing skill and hook configurations against it before June 18; update any shell aliases, CI scripts, or documentation that invoke gemini or gemini-cli to use the new binary.
  • Why trust it: Official announcement on the Google Developers Blog as part of Google I/O 2026; the June 18 cutoff date and user-tier details are stated explicitly; confirmed by coverage from The Register, TechCrunch, and MarkTechPost on May 19–20, 2026.
  • Skeptic check: Google's post acknowledges "no 1:1 feature parity right out of the gate" without specifying which features are missing — gap details may only surface after users migrate.

Claude Code v2.1.146 renames /simplify and fixes auto-mode handoff

  • Source: Anthropic / Claude Code official changelog
  • Link: Claude Code Changelog — code.claude.com
  • TL;DR: v2.1.146 (May 21) renames /simplify to /code-review and adds an optional effort-level argument so you can control how deep the review goes per invocation. More impactfully, auto mode was silently swallowing AskUserQuestion calls even when a user or skill had explicitly set up a human-in-the-loop step — this is now fixed, so explicit human handoffs always surface regardless of the mode. The release also fixes a Windows PowerShell CLI regression, broken MCP paginated resources and prompts, and /background incorrectly refusing skill-only commands, among 15+ total fixes.
  • What to do: Update any scripts or skill definitions that call /simplify to use /code-review; if you built workflows where agents were supposed to pause for user input and that wasn't happening in auto mode, retest after updating.
  • Why trust it: Official Claude Code changelog entry for v2.1.146, dated May 21, 2026, at code.claude.com/docs/en/changelog; specific command rename and bug descriptions are listed with the release notes.
  • Skeptic check: The changelog doesn't say whether the AskUserQuestion suppression was an intentional design that was reversed or an unintended regression — the blast radius of affected workflows is unknown.
