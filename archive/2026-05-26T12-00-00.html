Add a small codebase map to your agent's prompt to cut iterations and cost

  • Source: Zhuohan Gu, Qizheng Zhang, Omar Khattab, Samuel Madden — arXiv cs.CL / cs.AI, submitted May 19, 2026
  • Link: PEEK: Context Map as an Orientation Cache for Long-Context LLM Agents — arxiv.org
  • TL;DR: For agents that repeatedly work on the same codebase or document set, keeping a small structured "context map" in the prompt—updated after each session with what the agent learned—cuts the number of iterations the agent needs by 93–145 and reduces cost by 1.7–5.8× compared to the previous best approach.
  • What to do: For any agent that hits the same repo repeatedly (code review, documentation, test generation), maintain a brief structured summary in the system prompt—what the repo contains, key schemas, important constants, which files are historically most useful—and update it at the end of each session based on what the agent found useful.
  • Why trust it: Benchmarked on standardized long-context reasoning and information-aggregation tasks with comparisons to the ACE prompt-learning baseline; 6.3–34.0% accuracy improvement, 93–145 fewer iterations, 1.7–5.8× cost reduction vs. ACE; code is open source on GitHub.
  • Skeptic check: The full PEEK system requires three interacting components (Distiller, Cartographer, Evictor) that practitioners would need to build; a simpler manual version—maintaining a CLAUDE.md or INDEX.md and updating it each session—captures some benefit but probably not the full measured gain.

Claude Mythos briefly appeared as a toggle in public Claude Code

  • Source: BleepingComputer; WinBuzzer — May 25–26, 2026
  • Link: Anthropic's restricted Claude Mythos model may be coming to Claude Code — BleepingComputer
  • TL;DR: The model string claude-mythos-1-preview appeared briefly as a toggle in Claude Code's public interface on May 25 before being pulled—signaling that Anthropic is actively wiring the model (substantially more capable than Opus 4.7 on complex code and security tasks) into the standard Claude Code product.
  • What to do: Watch for a Mythos model option in Claude Code settings; when it appears, it will likely be the better choice for tasks requiring deep multi-file code reasoning, autonomous long-running coding sessions, or security auditing.
  • Why trust it: Multiple independent technology journalists confirmed the UI sighting on May 25; Anthropic has separately acknowledged Mythos is being prepared for Claude Code and Claude Security; about 50 partners have used the preview model to find 10,000+ high-severity vulnerabilities across production software.
  • Skeptic check: No public release date announced; the model may remain restricted to security partners for months; capability claims come from partner-reported security use cases, not general coding benchmarks comparable to what most practitioners run.
