Cursor 3.7 ships a live token breakdown of your agent's context

  • Source: Cursor — changelog v3.7 (June 4, 2026)
  • Link: Canvas Design Mode and Context Usage Report — Cursor changelog
  • TL;DR: Cursor 3.7 adds two features. First, ask your agent to produce a Context Usage Report and it generates an interactive canvas showing exactly where tokens are going: system prompt, tool definitions, rules, skills, and conversation history. Because it's a canvas, you can ask follow-up questions and the agent will customize the breakdown for you. Second, Design Mode is now available in canvases — instead of describing a UI change in text, you click to select and annotate elements directly on the rendered output, then let the agent act on your annotations.
  • What to do: Run a Context Usage Report in your next Cursor session — the breakdown frequently reveals that tool definitions or skills are consuming far more tokens than expected, which tells you exactly where to trim first when you're hitting context limits or watching costs climb.
  • Why trust it: Official Cursor changelog entry for v3.7, June 4, 2026; confirmed by releasebot.io and secondary coverage citing the same version number and feature descriptions.
  • Skeptic check: The report shows the token distribution at the moment you request it — context composition shifts as the conversation grows, so a snapshot taken at session start won't reflect what's consuming tokens mid-task.

Claude Code v2.1.163 adds admin version-pinning and scoped plugin governance

  • Source: Anthropic — Claude Code changelog v2.1.163 (June 4, 2026)
  • Link: Claude Code releases — GitHub
  • TL;DR: Two new managed settings land: requiredMinimumVersion and requiredMaximumVersion. If a user's Claude Code version falls outside the allowed range, the tool refuses to start and directs them to an approved version. A third setting, pluginSuggestionMarketplaces, lets admins allowlist specific org marketplaces so that context-aware plugin tips only suggest plugins from approved sources. For individual users, /plugin list (with --enabled/--disabled filters) now shows what's installed at a glance. Also fixes a bug where modifying thinking blocks in Opus 4.8 responses caused API errors.
  • What to do: If you manage Claude Code across a team, add requiredMinimumVersion to your managed settings config now to prevent users from running versions with known issues; pair it with pluginSuggestionMarketplaces to keep plugin suggestions pointed at your approved sources only.
  • Why trust it: Official Anthropic changelog for v2.1.163, June 4, 2026; confirmed by releasebot.io and claudeupdates.dev citing the same version and feature list.
  • Skeptic check: Version enforcement only fires at startup — a session already running when you push the policy update won't be terminated mid-task.

Programmatic Claude usage splits to its own credit pool on June 15 — 10 days out

  • Source: Anthropic (announced May 14, 2026; effective June 15, 2026)
  • Link: Use the Claude Agent SDK with your Claude plan — Anthropic Help Center
  • TL;DR: Starting June 15, claude -p, GitHub Actions integrations, and anything built on the Claude Agent SDK no longer draws from the same rate-limit pool as interactive Claude Code sessions. Instead it consumes a separate monthly credit billed at standard API token rates: $20 for Pro, $100 for Max 5x, $200 for Max 20x — per user, no rollover, no pooling across the org. Once the credit runs out, automated requests stop entirely unless you've manually enabled overflow billing. Interactive sessions (Claude Code in the terminal, claude.ai chat) are unaffected. Two model IDs also retire June 15, and the Agent SDK package is being renamed to drop "claude-code" from the name.
  • What to do: Before June 15, measure how much claude -p and Agent SDK usage your team runs per month; if it's likely to exceed your plan's credit limit, either enable overflow billing in the console, upgrade your plan, or move heavy automation to direct API keys before the cutover — otherwise automated jobs stop silently when the credit drains.
  • Why trust it: Official Anthropic announcement (May 14, 2026) and Help Center article, confirmed by TechTimes, codersera.com, and devtoolpicks.com — all citing the same credit amounts, affected surfaces, and June 15 effective date.
  • Skeptic check: Credit consumption at "standard API list rates" will vary significantly by model mix — a team using Opus 4.8 will exhaust the $100 Max 5x credit far faster than one using Haiku 4.5.
