Destyling tool-output injections drops prompt injection success from 61% to 10%

  • Source: Simon Willison's Weblog; Prompt Injection as Role Confusion (Ye, Cui, Hadfield-Menell — ICML 2026, arxiv 2603.12277)
  • Link: Simon Willison's writeup — Jun 22, 2026; arxiv.org/abs/2603.12277 — full paper
  • TL;DR: Language models infer who is speaking from the writing style of text, not from the role tag wrapping it. Injected content inside tool outputs can therefore "feel" like a system prompt if it is written in the same authoritative register. A new attack called CoT Forgery exploits this by planting fabricated chain-of-thought reasoning inside user messages or tool outputs; it achieves roughly 61% success at exfiltrating agent state across multiple tested models. The fix: rewrite ("destyle") injected-looking content into a neutral, non-authoritative format before it reaches the model. That alone drops attack success to roughly 10%.
  • What to do: Add a normalization pass to your tool output processing that strips command-tone language, first-person authority phrasing, and chain-of-thought formatting before the content enters the context window — anything that could make untrusted text sound like it came from the system prompt.
  • Why trust it: ICML 2026 accepted paper; attack success rates measured on multiple open- and closed-weight models using both StrongREJECT and agent-exfiltration benchmarks, with near-zero baseline rates for the comparison condition.
  • Skeptic check: Destyling is a post-hoc filter, not a structural fix — a targeted attacker who knows the filter's heuristics can craft injections that deliberately avoid the stylistic markers it looks for.

GitHub Copilot for JetBrains adds Claude agent provider, org agents, and CLI steering

  • Source: GitHub Changelog
  • Link: New features and Claude as agent provider preview in JetBrains IDEs — GitHub Changelog, Jun 22, 2026
  • TL;DR: The June 22 Copilot for JetBrains update ships six things at once: (1) Claude as a selectable agent provider in public preview — install Claude Code CLI, point the plugin at it under Settings > Tools > GitHub Copilot > Chat, then pick "Claude" in the agent picker; the Claude agent currently runs in bypass permissions mode, auto-approving all file edits and tool calls. (2) Org- and enterprise-level custom agents from GitHub now appear in the JetBrains agent picker. (3) Copilot CLI sessions support message queuing and mid-session steering — you can send follow-up instructions while the agent is still running. (4) A new agent debug logs summary view. (5) A /models slash command plus a context-window size picker in the model selector. (6) A per-turn AI credits indicator.
  • What to do: Install the Claude Code CLI locally, configure its path in JetBrains Copilot settings, and try Claude as your agent provider; treat bypass permissions mode as fully autonomous and review all changed files after each session — there is currently no per-call confirm dialog in this flow.
  • Why trust it: GitHub first-party changelog entry, dated June 22, 2026; no secondary corroboration required.
  • Skeptic check: Bypass mode means the agent can write and run anything without pausing — this is a meaningful security difference from the default Claude Code CLI experience, where you can set permission levels per tool category.

Claude Code subagent mined an example project and ported a 0.2B model to the browser — zero human code review

  • Source: Simon Willison's Weblog
  • Link: Porting the Moebius 0.2B image inpainting model to run in the browser with Claude Code — Simon Willison, Jun 22, 2026
  • TL;DR: Willison ran Claude Code as a parallel side-project to port Moebius — a 0.2B image inpainting model — from PyTorch/CUDA to ONNX Runtime Web on WebGPU so it runs entirely in a browser tab. Claude spawned a subagent to read through an existing whisper-web project and extracted the caches.open("transformers-cache") / CacheStorage API pattern for large file downloads, then applied it to the Moebius port. Willison never read any of the code; he only tested the output, suggested small features like a download progress bar, and pointed Claude at similar projects. The working demo and the full Claude Code transcript are both public.
  • What to do: When you have a scoped porting or conversion task where a working example exists elsewhere, point Claude Code at that example early and let a subagent mine it for patterns — this avoids the main agent having to rediscover infrastructure the example already solved.
  • Why trust it: Working browser demo published at simonw.github.io/moebius-web/; full Claude Code transcript published using the author's claude-code-transcripts tool; Willison confirmed the result by using it.
  • Skeptic check: This is one informal side-project on a small model — it shows the pattern works here, not that it generalizes to arbitrary model ports or larger architectures.
