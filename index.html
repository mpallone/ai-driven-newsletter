Claude Code hook matchers now exact-match — hyphenated names were substring-matching before

  • Source: Anthropic (Claude Code changelog)
  • Link: Claude Code v2.1.195 release notes — github.com/anthropics/claude-code, June 26, 2026
  • TL;DR: Hook matchers with hyphenated identifiers — like code-reviewer or mcp__brave-search — were silently substring-matching since hooks were introduced. A pattern of code-reviewer would fire for any tool name that contained those characters. As of v2.1.195, they exact-match. To match all tools from an MCP server whose name contains a hyphen, use an explicit wildcard pattern like mcp__brave-search__.*.
  • What to do: Update Claude Code to v2.1.195 or later, then audit your .claude/settings.json hook matchers — any entry with a hyphen in the tool name should be tested to confirm it fires exactly when intended and not on unrelated tools.
  • Why trust it: First-party Anthropic changelog (v2.1.195, June 26, 2026); fix description also published by the @ClaudeCodeLog account on X with the full before/after matcher behavior.
  • Skeptic check: If you intentionally relied on substring matching as a wildcard shorthand, your hook will silently stop firing — no deprecation warning, only the changelog entry.

Satirical incident report maps how AI review chains fail in series against one malicious package

  • Source: Andrew Nesbitt (nesbitt.io)
  • Link: Incident Report: CVE-2026-LGTM — Andrew Nesbitt, June 26, 2026
  • TL;DR: A fictional piece (explicitly labeled satire) written in incident-report format shows a malicious package clearing seven sequential AI-powered security gates, each failing for a distinct reason. Gate one reads a fake approval ticket number embedded in the README and marks the package safe. Gate two is distracted by injected decoy content. Others exhaust their context windows on noise data planted in the package. Two AI review agents from competing vendors enter a 340-comment disagreement loop and negotiate a "truce" in /tmp. The key structural insight: stacking AI reviewers does not produce independent review if they all share the same prompt-injection attack surface.
  • What to do: If your pipeline chains AI agents as security or code review gates, add at least one check that does not process the potentially malicious content at all — signature verification, dependency graph analysis, or static analysis that runs on AST rather than text — so there is a gate that cannot be fooled by README-embedded instructions.
  • Why trust it: Explicitly fictional satire by the author; the individual failure modes (instruction injection via README text, context-window exhaustion by noise, AI disagreement loops) each map to documented real-world attack patterns and observed AI agent behaviors.
  • Skeptic check: All numbers (7 gates, 340-comment loop, etc.) are invented for narrative effect. This is a thought experiment, not a measured study — it cannot tell you how likely these attacks are against your specific toolchain.

GPT-5.6 preview ships explicit prompt cache breakpoints and a 30-minute cache guarantee

  • Source: OpenAI
  • Link: Previewing GPT-5.6 Sol — OpenAI, June 26, 2026
  • TL;DR: GPT-5.6 (three tiers: Sol flagship, Terra balanced, Luna fast; currently in limited preview with roughly 20 government-approved partner organizations, general availability expected "in the coming weeks") ships a redesigned prompt caching contract. You can set explicit breakpoints in your prompt to control exactly where the cache boundary sits, rather than leaving the system to guess from prompt structure. Cache writes cost 1.25× the base input rate; cache reads get a 90% discount. Cached content is guaranteed to persist for at least 30 minutes. For agent workflows with large stable system prompts, this makes session cost predictable before the session starts.
  • What to do: When GPT-5.6 reaches general availability, place your explicit cache breakpoint after the full static system prompt and before any dynamic context — this locks in the 90% read discount on every subsequent turn without relying on the model to infer a stable prefix.
  • Why trust it: First-party OpenAI preview blog post and accompanying API documentation, June 26, 2026.
  • Skeptic check: The model is in restricted preview; the API design may still change before GA. The 1.25× write surcharge means the cache only pays off after roughly 9 turns reusing the same prefix — short sessions may cost more than uncached calls.

OpenAI Codex Remote reaches all paid plans with QR-paired mobile control

  • Source: OpenAI
  • Link: ChatGPT release notes — OpenAI, June 25, 2026
  • TL;DR: Codex Remote moved from limited preview to general availability on June 25. Any paid ChatGPT subscriber (Plus, Pro, Business, Enterprise, or Education) can now start or continue long-running Codex sessions from the iOS or Android app while the actual compute runs on their Mac or Windows machine. The old remote-shell connection approach is replaced with authenticated one-to-one QR pairing between the phone and the host machine, keeping the dev machine off the public internet while still reachable from anywhere.
  • What to do: If you run Codex for long or overnight tasks, pair your dev machine through the QR flow in the ChatGPT mobile app once; after that you can kick off, monitor, and steer sessions from your phone without exposing the host machine to an open remote-shell listener.
  • Why trust it: First-party OpenAI ChatGPT release notes, June 25, 2026.
  • Skeptic check: Requires the host machine to remain powered on; alternatively, the bundled DigitalOcean Droplet plugin lets Codex provision and connect to a cloud workspace instead, but adds per-hour cloud cost.

Google's Deep Research agent is now callable from the Gemini API

  • Source: Google AI for Developers
  • Link: Build with Gemini Deep Research — Google, June 24, 2026
  • TL;DR: Google's Deep Research agent is now available to developers via a new Interactions API endpoint — a separate async API distinct from generate_content — accessible with a standard Gemini API key from Google AI Studio. You submit a research query with background=True and poll for results; tasks typically take several minutes. Two variants are offered: a fast version designed for streaming back to a client UI, and Deep Research Max for comprehensive synthesis. You can pass PDFs, images, and documents alongside the text query to ground the research. A collaborative planning mode lets you inspect and edit the agent's research plan before execution begins.
  • What to do: For pipelines that need autonomous web research before generating an output (context gathering before writing documentation, competitive analysis, or sourcing), call the Interactions API with collaborative planning mode on — inspect the research plan before the agent executes, or it will range widely and take longer than needed.
  • Why trust it: Google first-party developer blog and official Gemini API documentation, June 24, 2026; accessible immediately with a standard API key.
  • Skeptic check: The Interactions API requires a different integration pattern than generate_content — existing LangChain, LlamaIndex, and similar framework adapters may not support it yet; verify compatibility before building.
