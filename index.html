claude agents --json now tells you why a session is blocked

  • Source: Anthropic — Claude Code changelog v2.1.162 (June 3, 2026)
  • Link: Claude Code release notes — claudeupdates.dev
  • TL;DR: claude agents --json now includes a waitingFor field for sessions in the waiting state, telling you exactly what the agent is blocked on (for example, a permission prompt) instead of leaving you to infer stuck state from idle time alone. Same release: /effort now persists your chosen level as the default for all new sessions and shows a confirmation when it will carry forward; --tools on native builds now provides real Grep and Glob search tools when explicitly listed in the flag; slash-command autocomplete fills the command into your prompt instead of executing it immediately — press Enter to run. Bug fixes cover a silent startup hang when the config directory is read-only, MCP server instability, file descriptor exhaustion, and plugin caching failures. Windsurf is now listed as Devin Desktop in the /ide menu and related commands, reflecting the editor's rebrand.
  • What to do: In any orchestrator that polls claude agents --json, add parsing for the new waitingFor field — you can now distinguish "blocked on a permission prompt" from "actively running" and respond differently (escalate to the user, send an auto-approval, or enforce a timeout). Set /effort to your preferred level once and stop re-entering it at the start of every session.
  • Why trust it: Official Anthropic changelog for v2.1.162, June 3, 2026; independently confirmed by claudeupdates.dev and claudelog.com citing the same version number, changes, and date.
  • Skeptic check: waitingFor is populated only while a session is in the waiting state — it does not tell you whether a long-running active session is making forward progress or has silently stalled.

Uber burned its 2026 AI coding budget in 4 months; cap is now $1,500/user/month per tool

  • Source: Bloomberg / TechCrunch (June 2, 2026)
  • Link: TechCrunch — Uber caps employee AI spending after blowing through budget in four months
  • TL;DR: Uber exhausted its entire 2026 budget for agentic coding tools — Cursor, Claude Code — in the first four months of the year. Individual engineers were running $500–$2,000/month in token spend before the caps. The company has now hard-capped all employees at $1,500/month per tool, with usage visible on an internal dashboard; caps can be exceeded with manager approval. Microsoft independently restricted Claude Code access for engineers in at least one major division, routing them to GitHub Copilot instead.
  • What to do: If you're deploying Claude Code or Cursor to a team without per-user spend tracking, add monitoring before you see the bill — Bloomberg and TechCrunch both confirm this burn-rate pattern is appearing across large organizations, and the first sign is typically a retrospective shock, not a live alert.
  • Why trust it: Bloomberg and TechCrunch both reported specific dollar figures on June 2, 2026, citing Uber's CTO by name and an internal tracking dashboard; two corroborating outlets with named sources reporting the same numbers.
  • Skeptic check: Uber's spend reflects their specific tool mix, usage intensity, and contract pricing — your per-user burn rate will differ, but the direction of surprise (faster-than-expected consumption) appears consistent across orgs.

GitHub Copilot in VSCode now defaults to Microsoft's in-house coding model

  • Source: Microsoft AI / Microsoft Build 2026 (June 2, 2026)
  • Link: Introducing MAI-Code-1-Flash — Microsoft AI
  • TL;DR: Microsoft shipped MAI-Code-1-Flash, a 5-billion-parameter coding model, to GitHub Copilot individual users in VSCode through both the manual model picker and the default auto-picker. The model was trained directly on production Copilot harnesses and licensed code — not just general code corpora — so it learned to interact with the surrounding editor APIs and tool protocols the way engineers actually use them. Microsoft also announced MAI-Thinking-1, a 35-billion active-parameter reasoning model (sparse MoE, 256K-token context), now available in private preview on Azure AI Foundry.
  • What to do: If you use GitHub Copilot in VSCode, check which model the auto-picker is currently selecting — your default may have changed to MAI-Code-1-Flash. If response quality has shifted noticeably, this model switch is the reason.
  • Why trust it: Official Microsoft announcement at Build 2026 on June 2; training methodology and SWE-Bench Pro comparison appear in the primary announcement; multiple outlets confirmed the VSCode rollout on the same date.
  • Skeptic check: SWE-Bench Pro scores measure isolated, single-repository fix tasks — quality for your specific multi-file, multi-turn workflows may differ significantly from the benchmark result.
