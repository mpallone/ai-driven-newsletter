Claude Code v2.1.196 fixes a background-session data-loss bug, adds org model defaults

  • Source: Anthropic
  • Link: Claude Code releases — GitHub, June 29, 2026
  • TL;DR: v2.1.196 fixes a critical bug where waking a background job would silently delete its transcript and re-run the original prompt from scratch — the transcript is now set aside rather than deleted. It also adds org-level default model configuration (admins set it in the org console; it appears as "Org default" or "Role default" in /model for users who haven't chosen manually), readable auto-generated session names at start, and clickable file attachments in chat (Cmd/Ctrl-click opens the file in Finder/Explorer). Remote Control is now disabled when ANTHROPIC_BASE_URL points at a non-Anthropic host.
  • What to do: Update to v2.1.196 now if you run background agents — the previous transcript-deletion bug could silently restart long-running tasks. If you manage a team, configure your org's default model in the admin console so new members get the right starting point without manual setup.
  • Why trust it: Anthropic's official changelog confirmed via @ClaudeCodeLog on X (changelog post from June 29, 2026) and the npm version record showing v2.1.196 published June 29; no independent audit of bug severity claimed.
  • Skeptic check: The transcript-deletion bug only triggered when waking a specific type of background job where the transcript probe misread a real transcript — not every background session was at risk.

Cursor iOS lets you launch and steer cloud agents from your phone

  • Source: Cursor
  • Link: Cursor iOS mobile app — Cursor changelog, June 29, 2026
  • TL;DR: Cursor launched a public iOS beta on June 29 for all paid plans. You can start always-on cloud agents directly from the app, move a session from your laptop to the cloud (so it keeps running when the laptop closes), continue steering a locally running agent from your phone via Remote Control, and receive push notifications when an agent finishes or needs input. Cloud agents run in isolated VMs with full dev environments. Cursor is offering 75% off Composer 2.5 cloud-agent runs through July 5.
  • What to do: If you use a paid Cursor plan and want to hand off long agent runs without keeping your laptop open, install the iOS beta and try moving a session to the cloud — the 75% discount through July 5 makes it cheap to test.
  • Why trust it: Official Cursor changelog entry corroborated by 9to5Mac coverage on June 29, 2026; feature set is concrete and specific, not marketing language.
  • Skeptic check: Public beta — iOS background-refresh policies may limit notification reliability. Cloud agent pricing after the discount period isn't stated in the launch post.

Open-source Ornith-1.0 models generate their own agent scaffold during training

  • Source: DeepReinforce (surfaced via Simon Willison, June 29, 2026)
  • Link: Ornith-1.0: Self-Scaffolding LLMs for Agentic Coding — DeepReinforce blog
  • TL;DR: DeepReinforce released Ornith-1.0, a family of MIT-licensed open-weight coding models (9B Dense, 31B Dense, 35B MoE, 397B MoE) built on Gemma 4 and Qwen 3.5 bases. The distinguishing feature: during reinforcement learning training, the model learns to generate both the solution and the task-specific scaffold (retry logic, tool orchestration, memory layout) simultaneously. In practice this means the model adapts its own harness rather than relying on a human-engineered one. All variants are on Hugging Face (MIT license); the 9B and 35B are available on Ollama as ornith:9b (5.6 GB) and ornith:35b (21 GB) right now.
  • What to do: If you're evaluating local open-source models for an agentic coding setup and have been spending time hand-crafting scaffolds, run ollama pull ornith:9b and test how much scaffold design the model handles on its own before you invest in custom harness engineering.
  • Why trust it: DeepReinforce published benchmark results (9B: 43.1 Terminal-Bench 2.1, 69.4 SWE-Bench Verified; 397B MoE: 77.5 Terminal-Bench 2.1, 82.4 SWE-Bench Verified); model weights and MIT license are live on Hugging Face. Benchmarks are self-reported by the releasing team.
  • Skeptic check: The claim that self-scaffolding reduces harness engineering work hasn't been measured against a "manually scaffolded baseline" on the same tasks — benchmark numbers show coding performance, not scaffold complexity reduction. SWE-Bench Verified scores for open models have varied significantly when reproduced independently.
