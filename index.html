Comma-separated hook matchers in Claude Code silently never fired — now fixed

  • Source: Anthropic — Claude Code changelog
  • Link: Claude Code changelog — v2.1.191, June 24, 2026
  • TL;DR: If you specified multiple tools as a comma-separated string in a Claude Code hook matcher (e.g., matcher: "Bash,PowerShell"), those hooks never fired — silently, with no error message. Any automation you set up with this pattern was not running. Fixed in v2.1.191.
  • What to do: After updating to v2.1.191, audit your hooks config for comma-separated matchers and verify they now fire correctly; if you used this pattern, assume the automation was not running and review any gaps it should have caught.
  • Why trust it: Anthropic first-party changelog, exact version v2.1.191, dated June 24, 2026; the bug is described with the exact matcher syntax that triggered it.
  • Skeptic check: —

Claude Code v2.1.187: sandbox.credentials blocks credential reads; MCP hang eliminated

  • Source: Anthropic — Claude Code changelog
  • Link: Claude Code changelog — v2.1.187, June 23, 2026
  • TL;DR: A new sandbox.credentials setting blocks sandboxed bash commands from reading credential files (e.g., ~/.aws/credentials) and secret environment variables. Also: the five-minute silent hang when a remote MCP tool call gets no response is replaced by an immediate abort with an error (overridable with CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT), and a structured-output bug where the model could re-invoke StructuredOutput indefinitely after a successful call is fixed.
  • What to do: Enable sandbox.credentials in your Claude Code config if you run sandboxed sessions in shared or CI environments to prevent the agent from reading local credentials; also confirm remote MCP integrations now surface errors promptly instead of hanging for five minutes.
  • Why trust it: Anthropic first-party changelog, exact version v2.1.187, dated June 23, 2026.
  • Skeptic check: The credential blocklist covers files Anthropic chose to enumerate; credentials stored in non-standard locations or env vars not flagged as secret may still be readable by sandboxed commands.

Claude Code v2.1.191: MCP discovery retries transient errors; streaming CPU drops ~37%

  • Source: Anthropic — Claude Code changelog
  • Link: Claude Code changelog — v2.1.191, June 24, 2026
  • TL;DR: MCP capability discovery (tools/list, prompts/list, resources/list) now retries on transient network errors instead of failing permanently. MCP OAuth discovery and token requests also retry once on transient errors; headless environments skip the browser popup and go directly to the paste-the-URL flow. Separately, CPU usage during streaming responses dropped ~37% by coalescing terminal updates to a 100 ms window.
  • What to do: Upgrade to v2.1.191 for more reliable MCP connections on flaky or high-latency networks; the CPU improvement is automatic — no config change needed.
  • Why trust it: Anthropic first-party changelog, exact version v2.1.191, dated June 24, 2026; the 37% CPU figure is specific enough to reflect an internal benchmark.
  • Skeptic check: The CPU measurement is self-reported and will vary by session length, terminal emulator, and machine; your savings may differ.

Claude Tag launches as a shared async agent inside Slack channels for Enterprise and Team

  • Source: Anthropic
  • Link: Introducing Claude Tag — Anthropic, June 23, 2026
  • TL;DR: Anthropic launched Claude Tag in beta for Enterprise and Team customers. You add Claude to selected Slack channels; anyone in the channel can @Claude to delegate a task asynchronously. Claude accesses approved tools, connected codebases, and channel context, then posts results back to the same thread. An ambient mode lets Claude proactively surface items and follow up on forgotten threads. Admins control which tools and data each channel can access, set per-channel token budgets, and view per-request activity logs. The product runs on Opus 4.8. Anthropic reports that 65% of their own product team's code is produced by an internal version of the same setup.
  • What to do: If you're on Enterprise or Team, pilot Claude Tag on a single Slack channel with a narrow, repeatable task class (PR summaries, daily triage, doc drafts) before expanding — the channel-scoped tool controls and token budgets let you limit blast radius while you learn what the shared-agent model does well in your workflow.
  • Why trust it: Primary source is Anthropic's own announcement. The 65% code stat is a first-party internal claim. Multiple independent outlets (TechCrunch, The Decoder, Neowin) corroborate the feature set from the same announcement date.
  • Skeptic check: The 65% figure comes from Anthropic's internal deployment, which they presumably optimized heavily for; it does not predict adoption rates or output quality for average enterprise teams.
